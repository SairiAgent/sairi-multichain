# Security

Experimental and unaudited. Do not deposit funds or deploy this prototype to any mainnet. Testnet deployment is limited to the maintainer-run, valueless-token procedure in docs/TESTNET_RUNBOOK.md. Report suspected vulnerabilities privately via GitHub private vulnerability reporting when enabled; do not post exploit details against live systems in public issues. If private reporting is unavailable, open an issue requesting a private contact without exploit details. No bug bounty is offered.
